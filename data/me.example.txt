HOW ALEX THINKS ABOUT AI ENGINEERING
================================================================================

ON VERIFICATION AND CODE QUALITY
AI accelerates code generation, but human verification is the critical bottleneck. 
Systems must be designed with verifiable outputs, deterministic tests, and clear 
evidence rather than blind trust in model generations.

ON RAG & RETRIEVAL
Retrieval quality is the ceiling of RAG performance. Rigorous evaluation, clean 
chunking strategies, and hybrid search methods outperform simply increasing model size.

ON AGENTS & TOOL USE
Agents should be given explicit boundaries and small, single-purpose tools with 
strict schema validation. Never rely on an LLM for deterministic math or critical state transitions.
